# ShopRise

Frontend implementation of the [ShopRise Figma design](https://www.figma.com/design/WUGwoxQhJrBTTfmuue0BMA/ShopRise--Copy-) — a classified marketplace for buying and selling new and used items.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS v4

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project Status

This is a **frontend-only** learning project. UI is built step-by-step from the Figma design using mock/static data — no backend, API routes, or authentication.
